# Cleanroom 1.12.2

本文件只在 NeoForge 1.21.1 基线验收后、用户明确指定 Cleanroom 1.12.2 迁移时读取。Minecraft 1.12.2 在本 skill 中仅对应 Cleanroom loader，不对应独立 Forge 1.12.2 目标。用户提供的网站在审计时受到 HTTP 429，因此以 CleanroomMC 官方 GitHub 源码和模板作为主要证据。

## 官方资料与固定快照

- Wiki：[CleanroomMC/Website](https://github.com/CleanroomMC/Website)，审计提交 `89314645e4e8b713688ba49ea6f84cbffd30cac7`。
- 模板：[CleanroomMC/CleanroomModTemplate](https://github.com/CleanroomMC/CleanroomModTemplate)，审计提交 `935558879c66eede20591e0b21793cabcff3363b`。
- 开发环境：[CleanroomMC/ForgeDevEnv](https://github.com/CleanroomMC/ForgeDevEnv)，审计提交 `807478aff106f33219b439296ed2792b171ccf69`。
- 构建插件：[CleanroomMC/CleanroomGradle](https://github.com/CleanroomMC/CleanroomGradle)，审计提交 `d5dd0d1e53f6628ec6b16a68560f4fe854a9116b`。

## 工具链与模板

- 目标 Minecraft：`1.12.2`。
- 当前模板使用 Unimined fork、MCP stable `39-1.12`、Cleanroom loader `0.6.10-alpha`、`runClient`/`runServer`/`genSources` 和 Java 25 toolchain；这不是对所有 1.12.2 运行时的承诺，必须以项目模板、CI 和 Cleanroom 发行要求为准。
- 常见文件：`gradlew*`、`build.gradle`、`settings.gradle`、`gradle.properties`、`src/main/java`、`src/main/resources`、`src/main/resource-templates`。
- `gradle.properties` 常维护 `mod_version`、`root_package`、`mod_id`、`mod_name`、`use_access_transformer`、`is_coremod`；当前模板是否启用其他开关以其文件为准。
- 依赖使用 `modImplementation`/`modRuntimeOnly`；不要把旧式 `fg.deobf()`/`rfg.deobf()` 迁入模板。
- Blossom 替换资源模板；`mcmod.info`、`pack.mcmeta` 和 `${mod_id}_at.cfg` 可能由模板生成。

## 1.12.2 API 和侧

- 生命周期是旧版 Forge 事件：`FMLConstructionEvent`、`FMLPreInitializationEvent`、`FMLInitializationEvent`、`FMLPostInitializationEvent`、`FMLLoadCompleteEvent`。
- 普通事件使用 `MinecraftForge.EVENT_BUS`、`@SubscribeEvent`、`@EventBusSubscriber`。
- 逻辑侧使用 `World#isRemote`；物理侧可用 `FMLLaunchHandler.side` 或 `FMLCommonHandler.instance().getSide()`，按项目依赖核对。
- `@Mod` 可声明 `clientSideOnly`/`serverSideOnly`；客户端类仍应隔离。
- block 更新 flag：`1` 通知邻居、`2` 发送客户端、`4` 不更新渲染、`8` 立即渲染更新、`16` 阻止观察者检测。只在确认为 1.12.2 目标代码时使用。

## Mixin、AT 与移植陷阱

- CleanMix `0.2.9`、MixinBooter `11.x` 的配置通过 `MixinConfigs` 或 `MixinConnector` manifest 属性注册；11.x 后不要照搬旧 early/late loader 分离。
- Access Transformer 默认 `src/main/resources/${mod_id}_at.cfg`，使用 MCP 名称，构建时转换为 SRG 名称。
- 类加载器注入使用 `Launch.classLoader.addURL()`，不要强转 AppClassLoader。
- `ScriptEngineManager` 使用 `Launch.classLoader`；ASM visitors 使用 `Opcodes.ASM9`；final 字段优先 AT 或 `ReflectionHackery`。
- 避免直接调用 `org.lwjglx`；核对 `javax`/`jakarta`、Guava、FastUtil 和其他库版本差异。
